# codex中转站会不会动我的代码，把这事讲透

![](https://cdn.laoshoucun.com/web/2026/10/codex-zz-a-20261010.jpg)

有朋友私下问我，把代码交给 codex中转站，会不会被它拿走。这个问题问得对，我用之前也担心过，今天就把它讲透。

## 中转站到底做了什么

它干的事是转发。你在 Codex 里敲一条命令，请求发到中转站的服务器，它再替你发到海外的模型那边，拿到结果传回来。它是一段管道，不是一个能把你的项目拷走的软件。你本地那台机器上有什么，它不知道。

## 真正该防的是什么

行内说的猫腻是掺水，就是你付的是甲模型的账，它偷偷拿乙模型给你答。这种才伤你。要防这个，看两条就够。一是它接的是不是官方原生接口，二是每一次调用有没有记录可查。这两样摆在那，掺水就藏不住。

## 我自己的用法

偏日常的活我都在 Codex 里跑，读文件、改函数、写测试，这些走中转站没顾虑。手上那点真敏感的，比如带客户数据的东西，我本来也不往外发，这是用任何在线模型都一样的习惯，不是在单挑中转站的毛病。

## 一句话结论

它是一段管道，不是仓库。你担心的方向如果放在掺水换模型上，那就去查它的调用记录。我把这一套用下来，后台每次调用的模型和用量都能翻出来，这一点让我踏实。

想自己验的话，注册一个号，建一个密钥，把地址接上，跑几天看看后台记录。我自己的这套就是在 https://3aic.com/ 上配起来的。
