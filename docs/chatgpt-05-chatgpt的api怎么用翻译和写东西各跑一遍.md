# chatgpt的api怎么用，翻译和写东西各跑一遍

![](https://cdn.laoshoucun.com/web/2026/10/chatgpt-zz-a-20261010.jpg)

有人拿着 key 不知道从哪儿下手。我今天不空讲，直接拿两个活跑一遍，你看完就知道 chatgpt 的 api 怎么用。

## 准备两样东西

一个是密钥，在你注册的站上密钥页建一个。一个是地址，用站上的接口地址。两样都拿到，剩下的就看你在哪儿用。

## 活一 翻译一段文字

我在客户端里开一个对话，让它把一段英文产品说明翻成中文。敲进去，几秒钟出结果。想固定风格，就加一句要求，比如保留专业词不翻。这类活它做得稳。

## 活二 把一段笔记整理成清单

我把一段乱糟糟的会议笔记贴进去，让它按主题分成几条。它先归了类，我看了觉得有两条该合并，就补一句让它合，它照着调了。这种先出稿再微调的用法，比一次写完美省劲。

## 放到脚本里也能用

你要是会写点代码，把地址和密钥配进脚本，让程序自己去调也行。接口是标准的那种，官方文档里的示例改一下地址就能跑。

## 一个提醒

地址和密钥要一起配。只填密钥不填地址，程序会去连官方域名，在国内会超时。这是新手最常撞的一下。

想自己跑一遍的话，注册一个号，建一个密钥，把地址接上就能用。我自己的这套就是在 https://3aic.com/ 上跑起来的。
