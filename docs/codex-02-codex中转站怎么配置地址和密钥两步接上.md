# codex中转站怎么配置，地址和密钥两步接上

![](https://cdn.laoshoucun.com/web/2026/10/codex-zz-b-20261010.jpg)

上周帮同事把他电脑上的 Codex 接到中转站，从打开设置到跑通第一条命令，前后不到五分钟。我把这两步记下来，照着做基本不会出错。

## 先拿到密钥

去站上注册一个号，邮箱收个验证就过了，然后在站内找到 API 密钥那一页，自己建一个。密钥就是一串字符，建完复制好，页面关掉之前别弄丢。

## 再把地址改过来

Codex 默认去敲官方的服务器，这里要把它指到中转站上。要设两样东西，一个 OPENAI_API_KEY 填你刚建的密钥，一个 OPENAI_BASE_URL 填站上的接口地址。命令行里用两行 setx 就能设，设完关掉终端重开一次，环境变量才生效。

很多人第一次装完说用不了，问题多半出在这。只填了密钥，地址没改，程序照样去敲官方那个域名，国内网络敲不通，就一直转圈。这两样是一对，缺一样都不行。

## 跑通是什么样

同事那台是 Windows，我先用 setx 把两个变量写进去，重开终端，敲 codex 回车，它认到了新地址，问要不要登录，直接过了。第一条命令我让他用最简单的，让 Codex 读一个本地文件，改一行注释。几秒钟就出结果，看到它真的动文件了，这条链路就算通了。

## 换工具也不用重来

密钥和地址这两样，任何支持自定义 API 地址的工具都认。你换一个客户端，把这两样填进去，照样能用，不用重新注册账号。

我自己的这套就是在 https://3aic.com/ 上配的，地址和密钥填进去，重启一次就通了。
