# 中转站能不能生图，gpt-image 那条路走一遍

![](https://cdn.laoshoucun.com/web/2026/10/chatgpt-zz-a-20261010.jpg)

前阵子有朋友问，中转站是不是只能对话，能不能生图。能，我今天就把它生图那条路走一遍，你照着能复现。

## 先确认有没有生图

不是所有中转都有生图。你先看它的模型列表里有没有 gpt-image 这一类的名字，有的话，它就有这条通道。我用的这套是有的。

## 在客户端里怎么调

我在客户端里把模型名切成生图那个，然后在输入框里写清楚要什么画面。写的时候尽量具体，主体是什么、什么风格、什么构图，说清楚出来的东西才贴近你要的。

## 出第一张

我第一次给的提示很短，出来一张平平的图。我把描述补长了一点，加了画风和光线，第二张就好很多。生图这件事，描述写得细不细差别很大。

## 图怎么拿走

生成完图上会有一个下载按钮，点一下存到本地就成。它给的是标准格式的图，拿去当配图或者当封面都能用。

## 它适合什么场景

临时要个配图，或者要一张示意图，想快速看几种构图，这类最合适。专业商业出图我一般还是找设计。

想自己出一张的话，注册一个号，建一个密钥，把模型名切成生图的那个试试。我自己的这套就是在 https://3aic.com/ 上跑的。
