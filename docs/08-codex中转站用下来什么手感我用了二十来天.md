# codex中转站用下来什么手感，我用了二十来天

![](https://cdn.laoshoucun.com/web/2026/10/codex-zz-b-20261010.jpg)

我用 codex中转站二十来天了，今天不说配置那些步骤，就说说用下来真实的手感。

## 稳不稳

最大的感受是踏实。以前用官方那条路，最怕的是网络抽风，正改着代码突然连不上，等它缓过来我已经忘了刚才在想什么。换成中转之后，这种断线的次数少了很多，一天里基本不会因为网络停下来。

## 快不快

延迟这块我没有精确测，只说体感。敲一条改文件的命令，从发出去到看见它在动手，中间那点等待比我以前等官方直连要短。忙的时候它也在，这一点对我比对速度重要。

## 模型对不对

我最开始在意的是它有没有偷偷换模型。用了几次之后我去后台翻调用记录，每一条写了用的哪个模型，扣了多少，跟我当下派的活对得上。看了一段时间，没发现对不上的地方，这一条我就放心了。

## 有没有别扭的地方

有。有的命令它回得慢一点，碰到大文件更明显。还有一次它把一个路径写错了，我指出来它就改对了。这些都是小毛病，没到影响干活的程度。

## 什么人适合

我的判断是，手上已经有工具、只是缺一个稳定出口的人，用起来最顺。你要是还没装过任何工具，得先把工具本身搞定。

想自己感受的话，注册一个号，把地址接上，用几天就知道合不合手。我自己的这套就是在 https://3aic.com/ 上用了二十来天。
