# chatgpt中转站怎么在客户端里用，地址密钥填一遍

![](https://cdn.laoshoucun.com/web/2026/10/chatgpt-zz-a-20261010.jpg)

很多人手上已经有一个第三方客户端，就是不知道中转该怎么接进去。我拿最常见的做法讲一遍，核心就是填两样东西。

## 客户端里找什么

打开你的客户端，进到模型设置或者 API 设置那一栏。里面一般有两个输入框，一个叫接口地址或者 base url，一个叫密钥或者 api key。这两个填上就成，别的不用动。

## 两样分别填什么

地址填站上的接口地址，它一般是 OpenAI 兼容的那种。密钥填你在站内密钥页建的那一串。填完保存，有的客户端会让你点一下测试，能通就直接用了。

## 常见的一个错

有人只填了密钥，地址那一栏空着，结果一直报连不上。这是因为客户端默认还去连官方的域名，国内网络连不通。地址和密钥这两样是一起填的，少一样都不行。

## 填完怎么确认

保存之后发一句话试试，比如让它把一段英文翻成中文。有回复，就说明这条路通了。再不行，去看客户端的日志，报的是超时还是鉴权失败，超时多半是地址没填对。

## 换个客户端也一样

这套填法在支持自定义地址的客户端里都通用。你换一个软件，地址和密钥填进去就行，不用重新注册账号。

想自己接一遍的话，注册一个号，建一个密钥，把地址和密钥填进客户端。我自己的那个客户端就是在 https://3aic.com/ 上接起来的。
