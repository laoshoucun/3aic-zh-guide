# codex中转站能用自己账号吗，说清楚这件事

![](https://cdn.laoshoucun.com/web/2026/10/codex-zz-b-20261010.jpg)

经常有人问我，用 codex中转站能不能绑自己的账号。这个问题我分两种情形说，一种是你登录用的账号，一种是你已经付费开通的那种账号。

## 登录用的账号

在中转站这边，你自己注册一个号，邮箱收个验证码就过了，不用去注册海外的账号，也不用过手机验证那一关。用它拿到的密钥只在这一个站里有效，跟官方那边没有账号关系。

## 已经付费的那种账号

如果你手上已经有一份官方订阅，想一边留着一边用中转站，也不冲突。两边是各自独立的路，你原来的订阅照常用，中转站这边单独注册单独用，互不干扰。

## 能接哪些工具

中转站是 API 出口，不是某一个定死的软件。你原来用 Codex，那就把 Codex 的地址改过来。你原来用别的支持自定义地址的客户端，一样填密钥和地址就行。工具不用换，账号体系也不用迁。

## 有一件事先说清楚

中转站这边是你自己注册的号，跟你官方的账号是两套。你原来的官方账号照常用，中转站这个是单独的一条路，互不影响。

想用的话，去站上注册一个号，建一个密钥，把地址填进去就能跑。我自己的这套就是在 https://3aic.com/ 上配起来的。
