# codex的api怎么配置，从密钥到跑通第一条

![](https://cdn.laoshoucun.com/web/2026/10/codex-zz-b-20261010.jpg)

上个月我照着文档把 codex 的 api 配了一遍，中间走了点弯路。今天把从建密钥到跑通第一条命令的完整过程写下来，给同样第一次弄的人省点时间。

## 先弄清要配的是哪几样

Codex 走的是 API，不是网页。你要准备的就三样，一个接口地址，一个密钥，一个模型名。地址和密钥是必填的，模型名不填它就按默认的来。

## 密钥怎么建

到你选的站上注册一个号，登录后在站内找 API 密钥那一页，新建一个。建完会给你一串字符，这就是 Key，复制存好。别去用别人共享的密钥，自己建一个最省事。

## 地址填在哪

如果那个站是 OpenAI 兼容的，那就把地址填成它的接口地址。Windows 上开一个命令行，敲两行 setx，一个设 OPENAI_API_KEY，一个设 OPENAI_BASE_URL。敲完关掉窗口重开，环境变量才读得到。

## 第一次跑通的样子

我重开终端后敲 codex 回车，它读到了新地址，没有再去连官方那个域名。然后我给了它一个最简单的活，让它在当前目录里找一个文件，把里面一句注释改掉。几秒钟后它回了结果，文件也真的变了。到这一步，配置就算完成了。

## 我踩过的坑

我第一次没设地址，只填了密钥，命令敲下去一直转圈，最后报超时。后来才明白，它默认去连海外的官方域名，国内网络连不上。地址和密钥这两样是一起用的，少哪一样都不行。

我自己的这套就是在 https://3aic.com/ 上配的，把地址和密钥填进去，重启一次就通了。
