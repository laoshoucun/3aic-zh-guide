# codex中转站怎么使用，拿个真任务走一遍

![](https://cdn.laoshoucun.com/web/2026/10/codex-zz-a-20261010.jpg)

光说配置有点干，我拿手上一个真任务，把 codex中转站怎么使用走一遍，你能看到它在一个普通工作日里是怎么用的。

## 我给它派了什么活

那天我要给一个老项目加一个导出按钮，代码我不想从头翻。我在项目根目录打开终端，先让它把跟导出有关的文件找出来，报给我一份清单，我先看它认不认得这套代码。

## 接着让它动手

清单出来之后，我挑了两个文件让它改，一个是前端那个按钮，一个是后端的导出函数。改之前我先 git commit 了一次，留着退路。它给了 diff，我扫了一遍，逻辑没问题，就让它写进去。

## 中途卡了一下

它第一次把导出格式写成了 json，我要的是 csv。我没重来，直接把要求补了一句，让它只改那一处格式，它照着调了。这种把话讲清楚再让它改的做法，比推倒重来快得多。

## 收尾

跑完之后我本地起服务点了一遍，导出的文件能打开，字段也对。整件事大概花了二十来分钟，里面我真正动手的只有 commit 和那一次补充说明。

## 我的习惯

我一般把活拆小一点给它，一次一个文件或者一个函数，比一口气让它改一大片要稳。删文件这类不能回头的操作，我会先自己看一眼它想删什么。

想自己走一遍的话，注册一个号，建一个密钥，把地址接上就能开工。我自己的这套就是在 https://3aic.com/ 上跑起来的。
